Each employee signs into her app with her name and her own personal code. Set the code here — tell it to her in person, never in a group chat or email thread. A code is blank until you set it; an employee with no code cannot sign in at all.

This Month’s Focus — set the monthly tasks (Krystal only)

TO-DO in every house for a whole month, then it rotates — not a check or inspection. Set 1–2 tasks for the month (sometimes more, depending on the task and the season). They last the whole month so every house gets done properly, then next month you set the next task(s) here and it rotates. The employee sees these in her app under “This Month’s Focus” and ticks each one off per house.

How she gets the update: this list is saved in the app’s shared data. On one phone / same browser it shows in her app straight away. On different phones it travels with the JSON export / import until the shared backend is connected — then it syncs automatically when you save here, with no separate message needed. The monthly tasks are also included in the day JSON export below.

What to use — Supplies Guide — edit (Krystal only)

The employee sees this in her app as “What to use — Supplies Guide”, by the cleaning supplies.
